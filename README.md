# 📱 PhonePe Pulse Data Analysis

## 📌 Overview

This project analyzes digital payment trends in India using the **PhonePe Pulse** dataset.

The analysis focuses on understanding transaction patterns, payment activity, geographic trends, and user behavior across Indian states and districts. An interactive **Power BI dashboard** was developed to transform the raw data into meaningful visual insights.

---

## 🎯 Objectives

- Analyze digital payment transaction trends over time
- Understand transaction volume and transaction value
- Compare payment activity across Indian states
- Identify regions with higher transaction activity
- Analyze user and device-related trends
- Build an interactive dashboard for exploring the insights

---

## 🗂️ Dataset

The project uses data from **PhonePe Pulse**, which provides aggregated information on digital payments across India.

**Dataset Source:**  

https://www.kaggle.com/datasets/nirmalcodes/phonepe-pulse-data-2018-2022

The dataset includes information related to:

- Transactions
- Transaction value
- States and districts
- User activity
- Device/brand information
- Time-based payment trends
